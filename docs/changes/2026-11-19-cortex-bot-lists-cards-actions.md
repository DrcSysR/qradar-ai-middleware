# 2026-11-19 — cortex-bot v2: списки з кнопками, структурована картка, дії

**Статус:** код готовий і перевірений (10 тестів + read-only прогін на живих даних mdlwr01), **НЕ розгорнуто** — чекає «добро».
Розгортання = `git push` у main `qradar-ai-middleware` (autoupdate на mdlwr01).

## Що змінилось
- «Кейси на перегляд» (Cortex) і «Відкриті офенси» (QRadar) — тепер не суцільний текст, а **картка-список**:
  по 6 позицій (`cortexbot_list_page`), кожна: severity/magnitude, #id, опис, хост/джерело, вердикт автотріажу +
  кнопки **Деталі · Дорозслідувати · Закрити**; «◀ Назад / Ще ▶ / Меню».
- **Деталі** — структурована картка: Огляд (опис, час, джерела, хости, користувачі, лічильники алертів, MITRE),
  🤖 автоматичний розбір, алерти (до 5), мережеві артефакти (кейс); для офенса — оцінки, події/потоки, категорії,
  джерела/цілі (IP), правила, оцінка моделі, лінк у QRadar.
- **Дорозслідувати** — аналіз Vertex (кейс: ті ж алерти й промпт, що в автотріажі; офенс: дані + вибірка 15 подій
  через AQL). Лише рекомендація в чат, **нічого не змінює**.
- **Закрити** — картка підтвердження з причинами; натиск причини = підтвердження. Cortex: resolved_false_positive /
  known_issue / security_testing / duplicate / other (admin-ключ `cortex_xdr_admin_api_key*`); QRadar: closing_reason
  1/2/3/104 + нотатка «Closed from Chat bot by …». Перед закриттям кейсу — перевірка поточного статусу; 409 від
  QRadar = «вже закрито»; захист від подвійного кліку.
- **Вимикач:** `cortexbot_write_enabled` (за замовчуванням **false**) — поки false, кнопки причин не показуються,
  а виклик напряму відхиляється на сервері. Вмикається в `config.json` без перезбірки.
- **Журнал дій:** `/opt/qradar-middleware/cortex_bot_audit.db` (таблиця `cortex_bot_audit`: ts, user, action,
  target, detail, result) + рядок AUDIT у `cortex_bot.log`.
- Решта звітів (закрито автотріажем, видалені ендпоінти, модель QRadar, останній 09:30) — без змін, текстом.

Перевірити, що в config.json є `cortex_xdr_admin_api_key_id/_key` (без них закриття кейсів повертає помилку,
нічого не змінюючи) і що токен QRadar має право закривати офенси; закриття дозволене всім членам `soc@`.

# 2026-11-19 — блок з необов'язковим строком

`блок IP [опис]` — wan-block **назавжди**; `блок IP 3г [опис]` — на 3 години (`2д` — діб; максимум `netdiag_pa_max_hours`, 720 год).
Строк розпізнається лише як ПЕРШИЙ токен після команди або після IP і лише з одиницею (г/год/h/д/d) — інакше `блок 1.2.3.4 тікет 123`
став би блоком на 123 години. Опис тепер необов'язковий (типово «без опису»). Діалог «Заблокувати IP»: випадайка «Строк» (Назавжди типово).
Для строкового блоку PA сам знімає тег по timeout; у `pa_blocks` нова колонка `until` (міграція ALTER на льоту), прострочені
у списку «блокування» не показуються; список показує «назавжди» або «до дд.мм гг:хх». Зняття `розблокуй IP` — для обох видів.
Код: `netdiag_pa.py`, `netdiag_ui.py`, `netdiag_bot.py`; тести `tests/test_netdiag_pa_block.py`. Відкат: попередній коміт.

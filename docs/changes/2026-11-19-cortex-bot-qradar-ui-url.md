# Cortex-бот: посилання на офенси QRadar ведуть на https://qradar.modern.org

Посилання «#id» у списку відкритих офенсів і кнопка «Відкрити в QRadar» у картці офенса будувались із `qradar_url` (IP консолі, https://172.17.61.184), у браузері це давало помилку сертифіката. Додано ключ `cortexbot_qradar_ui_url` (типово `https://qradar.modern.org`) лише для посилань людині (`ui_base()`); виклики API далі йдуть за `qradar_url`. Якщо ключ порожній — повертається `qradar_url`.

# 2026-11-19 — швидкі команди й памятка

Текстові команди повторюють кнопки меню: `діагностика <IP|MAC>` (або просто IP/MAC), `інтернет <IP> <строк>`,
`блок <IP> <опис>`, `розблокуй <IP>` (знімає і тимчасовий, і постійний wan-block; також `зняти блок`),
`блокування` / `список` (блокування з бота), `памятка` / `команди` (підказка), `меню`.
Памятка показується в меню (PA-команди — лише тим, кому дозволені дії на PA) і за командою `памятка`.
`діагностика` без IP/MAC — підказка. Код: `netdiag_pa.parse_command`, `netdiag_ui.memo`, `netdiag_bot` (MEMO_RE/DIAG_RE).
Тести: `tests/test_netdiag_pa_block.py`. Відкат: попередній коміт.

# Cortex-бот: «Закрити» відкриває діалог замість нового повідомлення внизу чату

Раніше кнопка «Закрити» у списку (і в картці деталей) відповідала НОВИМ повідомленням-підтвердженням у кінці треда — його треба було гортати. Тепер вона відкриває діалог (Chat `OPEN_DIALOG`) поверх чату:

- `c_case` / `c_off` повертають `actionResponse DIALOG` з тим самим набором причин (кнопки); «Скасувати» (`dlg_close`) просто закриває вікно.
- Клік по причині всередині діалогу (`x_case` / `x_off` з `isDialogEvent`) виконується синхронно (`do_close_case` / `do_close_offense`, ті самі перевірки, `cortexbot_write_enabled`, журнал дій, ліміт запитів) і закриває діалог, показуючи результат підказкою (`userFacingMessage`, ≤250 символів). У чат нічого не додається.
- Старі картки підтвердження з попередніх повідомлень продовжують працювати: поза діалогом `x_*` іде колишнім async-шляхом.
- Не змінено: Деталі, Дорозслідувати, звіти, права доступу (група soc@), kill-switch запису.

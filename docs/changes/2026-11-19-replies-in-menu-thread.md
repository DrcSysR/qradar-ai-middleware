# 2026-11-19 — усі відповіді на кнопки — тредом під меню

Синхронні відповіді на натиск кнопки (`NEW_MESSAGE`: підтвердження, списки, попередження, «Готую…», картка закриття, «Меню»)
тепер перепощуються через Chat API в тред натиснутого повідомлення (меню), а не окремим повідомленням у просторі.
Діалоги (`DIALOG`) і редагування на місці (`UPDATE_MESSAGE`) не змінюються; результати, що й раніше йшли асинхронно,
уже були в треді. Запасний варіант: якщо треду немає або Chat API відмовив — віддається звичайна синхронна відповідь,
нічого не губиться. Текстові команди (не кнопки) відповідають у треді власного повідомлення користувача.
Код: `in_thread()` у `netdiag_bot.py` і `cortex_bot.py`; тести `tests/test_netdiag_thread.py`, `tests/test_cortex_bot.py`.
Відкат: попередній коміт.

CRITICAL REMINDER: This SIEM rule detects Brute Force or Password Spraying attempts (at least 10 authentication failures for the same Username in 5 minutes). Your task is to determine if this is a benign user error (e.g., forgotten password, stale cached credentials on a mobile device) or a genuine malicious attack.
Analyze the provided authentication logs. Pay close attention to the 'Target_User', 'Source_IP', 'Failed_Attempts', and especially the number of 'Unique_Source_IPs'. Apply the following heuristics to map your findings to the scoring rubric:
1. Map to 0.0 - 0.3 (CLEAR FALSE POSITIVE) if all failed attempts originate from a SINGLE, recognized internal 'Source_IP' (e.g., a known user workstation or mobile device IP range), and the total 'Failed_Attempts' is moderate (e.g., 10-30). This strongly indicates a user typing the wrong password manually, or a device continuously trying to authenticate with expired cached credentials (e.g., email client or mapped drive). Verdict: 'Benign_User_Error_or_Cached_Credentials'.
2. Map to 0.4 - 0.6 (SUSPICIOUS BUT INCONCLUSIVE) if the failed attempts originate from a single UNKNOWN or external 'Source_IP' (e.g., via VPN or external gateway), OR if the 'Failed_Attempts' count is excessively high (e.g., hundreds of attempts from one IP) but all are unsuccessful. This is a suspicious targeted brute force attempt, but without evidence of a successful login, the immediate impact is low. Verdict: 'Targeted_Brute_Force_Unsuccessful'.
3. Map to 0.7 - 0.8 (HIGHLY SUSPICIOUS) if the failed attempts for the single user originate from MULTIPLE distinct 'Source_IP's (Unique_Source_IPs >= 3), especially if they are external or unrecognized. This indicates a distributed brute force or password spraying attack targeting this specific account. Verdict: 'Distributed_Brute_Force_Attack'.
4. Map to 0.9 - 1.0 (CONFIRMED COMPROMISE) if, IN ADDITION to the failed attempts, there is a subsequent SUCCESSFUL authentication (Logon Type 2, 3, or 10) for the 'Target_User' from one of the attacking 'Source_IP's. This critical pattern means the brute force attack succeeded and the account is compromised. Verdict: 'Successful_Brute_Force_Compromise'.

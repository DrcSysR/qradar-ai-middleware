REMINDER: This SIEM rule is susceptible to False Positives.
Prompt: Analyze Palo Alto firewall logs (Traffic End) for Command & Control (C2) beaconing from a compromised internal host.
Context: The SIEM rule triggered because the host made 50+ connections to the EXACT SAME external IP in 30 minutes. Known safe corporate apps (Google Workspace, Windows Updates) have already been filtered out.
Verdict Benign (Score 0.2): The connections are targeting known, legitimate infrastructure (e.g., a misconfigured legitimate external API or third-party business software) that was simply missing from the safe list.
Verdict Suspicious (Score 0.6): High connections to generic web hosting or CDNs (e.g., AWS, Azure) with apps like 'web-browsing' or 'ssl', where malicious intent is unclear but anomalous for the user.
Verdict Active_C2_Beaconing (Score 0.95+): CRITICAL. Periodic beacons to unknown/raw IPs, uncategorized URLs, dynamic DNS, or the 'App' field shows 'unknown-tcp', 'unknown-udp'. This is a confirmed C2 compromise.

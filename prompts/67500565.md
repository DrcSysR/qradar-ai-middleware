CRITICAL REMINDER: This offense tracks IT Administrators ('ME-Admins-List') authenticating on user workstations OUTSIDE the IT VLAN. Your task is to distinguish between authorized technical support and potential credential theft (Lateral Movement).
Context for this environment:
- SUPPORT TOOLS: Admins use DameWare for remote support. This often logs as Logon Type 3 (Network) or Type 10 (RemoteInteractive).
- RUN AS / UAC: Admins elevation on user machines (Run As) typically generates 'Success Audit: A logon was successful using explicit credentials' (QID 5000835) or Logon Type 3.
- ANOMALY: A full interactive session (Logon Type 2) or RDP (Logon Type 10) on a user's machine is a policy violation, as it implies the admin is using the machine as their own workstation.
Analyze the logs and apply these heuristics to the scoring rubric:
1. Map to 0.0 - 0.3 (CLEAR FALSE POSITIVE) if:
   - The login is via DameWare (look for 'DWRCS.exe' in Process or Logon Type 3/10) targeting 1-2 specific user workstations.
   - The event is an 'explicit credentials' logon (Run As) performed for a single maintenance task.
   Verdict: 'Authorized_Technical_Support'.
2. Map to 0.4 - 0.6 (SUSPICIOUS BUT INCONCLUSIVE) if:
   - The administrator performs a FULL interactive login (Logon Type 2) or RDP session (Type 10) on a user workstation without clear evidence of support tools like DameWare. This is a policy violation (admin should work from IT VLAN).
   Verdict: 'Policy_Violation_Full_Interactive_Login'.
3. Map to 0.9 - 1.0 (CONFIRMED COMPROMISE) if:
   - The admin account authenticates to MULTIPLE unique devices (Unique_Targets >= 3) in a short period from outside the IT VLAN.
   - The admin account logs in from an unusual Source_IP (e.g., a VPN range or a guest network) that doesn't match known support patterns.
   This strongly indicates hijacked credentials and active Lateral Movement.
   Verdict: 'Active_Lateral_Movement_Compromised_Admin'.

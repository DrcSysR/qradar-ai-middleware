CRITICAL REMINDER: This SIEM offense triggers when an IT Administrator (from the 'ME-Admins-List') successfully authenticates on a workstation that is located OUTSIDE the designated IT department VLAN. 
Context specific to this environment:
- It is NORMAL and expected for IT support staff to temporarily elevate privileges on a user's workstation using "Run As" or UAC prompts (which typically log as Logon Type 3 or specific Event Names) to perform maintenance or install software.
- It is HIGHLY ANOMALOUS and a potential policy violation or indicator of compromise if an administrator performs a FULL interactive desktop login (Logon Type 2 - Interactive / Console) or an RDP session (Logon Type 10 - RemoteInteractive) on a standard user's workstation, as administrators should use jump servers or their own dedicated IT workstations for full sessions.
Analyze the provided authentication logs. Pay very close attention to the 'Logon_Type', 'Event_Name', 'Admin_User', and 'Target_IP'. Apply the following heuristics to map your findings to the scoring rubric:
1. Map to 0.0 - 0.3 (CLEAR FALSE POSITIVE) if the authentication appears to be a temporary privilege elevation for support tasks. This is indicated by Logon Type 3 (Network logon, often used for admin shares or remote RPC) OR events explicitly related to "explicit credentials" (Event 5000835) combined with low event counts targeting a single user workstation. This confirms legitimate Helpdesk/IT support activity. Verdict: 'Authorized_Admin_Support_Task'.
2. Map to 0.4 - 0.6 (SUSPICIOUS BUT INCONCLUSIVE) if the administrator performs a FULL interactive desktop login (Logon Type 2) or RDP login (Logon Type 10) on a single user workstation. This suggests the admin is fully logging into the user's PC rather than just elevating a specific process. This is a policy violation and requires IT verification, but might not be a malicious compromise. Verdict: 'Policy_Violation_Full_Interactive_Login'.
3. Map to 0.9 - 1.0 (CONFIRMED COMPROMISE) if the administrator account exhibits Lateral Movement behavior: performing full interactive/RDP logins (Logon Type 2 or 10) or rapid network logons (Type 3) across MULTIPLE different 'Target_IP's within a short timeframe from outside the IT VLAN. This is a critical indicator that an attacker has stolen admin credentials and is actively scanning or moving across the user network. Verdict: 'Active_Lateral_Movement_Compromised_Admin'.

Prompt: Analyze authentication logs for human administrators. Differentiate between normal IT operations and lateral movement/credential abuse.
Context: Human admins should authenticate from dedicated IT subnets or Jump Servers.
Verdict Benign (Score 0.2): Admin logs into a standard user machine via Network Logon (Type 3) to provide remote support (e.g., accessing C$ share).
Verdict Compromised / Lateral Movement (Score 0.95): Admin account logs in via Interactive (Type 2) or RDP (Type 10) originating from a non-IT user subnet. OR, a single admin account performs Network Logons (Type 3) to multiple different servers within a short timeframe (indicates Pass-the-Hash or scripting from an unauthorized source).
